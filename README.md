Social Sparks! ⚡

A mobile application designed to help users, specifically **Cora**, overcome social anxiety by providing small, manageable "social sparks" based on the time of day.

## 🌟 Project Overview
Social Sparks! aims to bridge the gap between isolation and connection. By entering the current time of day, the app provides a tailored suggestion to encourage the user to reach out to a friend, family member, or colleague in a low-stress way.

## 🚀 Features
* **Time-Based Suggestions:** Custom logic for Morning, Afternoon, and Evening.
* **Calming UI:** A simple, gold-themed interface designed to reduce user stress.
* **Reset Functionality:** Easily clear inputs to try a different time of day.
* **Error Handling:** Friendly messages if a user enters an unrecognized time.


## 🛠️ Built With
* **Kotlin** - The primary programming language.
* **Android Studio** - The development environment.
* **XML** - Used for the layout and design.
* **GitHub Actions** - For automated building and testing.

## 📱 How to Use
1. Open the app on your Android device (or emulator).
2. Type a time of day into the input box (e.g., "Morning", "Afternoon", or "Evening").
3. Click the **"Get My Spark"** button.
4. Read your social suggestion and try to complete the task!
5. Press **"Reset"** to clear the screen.
